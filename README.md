# GlowCare

## Sobre o projeto

O GlowCare é um sistema web desenvolvido para auxiliar na organização da rotina de cuidados com a pele (skincare), permitindo que os usuários acompanhem seus produtos e organizem seus cuidados diários.

## Estrutura do projeto

O arquivo `index.html`, localizado na raiz do projeto, é responsável por redirecionar automaticamente o usuário para a pasta `frontend/`, onde está localizado o site.

```text
ProjetoGC/
│
├── index.html
│
└── frontend/
    └── Arquivos do site
```

## Como acessar

1. Abra o projeto em um navegador.
2. O arquivo `index.html` redirecionará automaticamente para a pasta `frontend/`.
3. Caso o redirecionamento não aconteça, clique no link disponibilizado na página.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

Facilitar a organização dos cuidados com a pele por meio de um sistema web simples e acessível.
